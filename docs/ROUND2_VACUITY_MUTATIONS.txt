WHY THIS FILE IS THE HONEST EVIDENCE
------------------------------------
These are TEST defects, not code defects: the production code these assertions
read is correct today, so every fixed assertion PASSES the moment it is written.
Failing-first does not apply, and a green run proves nothing about the fix.  What
does is the opposite: break the thing the assertion is supposed to notice, and
watch the assertion fail.

Method: one mutant at a time, applied in place to the worktree, the *specific*
test(s) run, the failure captured verbatim below, then `git checkout -- <file>`
so **no mutation is committed**.  Every mutant ran in a single pytest process
with `-q --no-header -p no:cacheprovider`; the raw logs are the /tmp/r2_mut_*.txt
files named per mutant.  After every revert the tree was re-checked
(`git status --short` shows only the four test files this pass edits; neither
`scripts/run_strategy_search.py` nor
`src/backtesting/strategy_search/screen.py` appears, i.e. no production file and
no mutation survived).
